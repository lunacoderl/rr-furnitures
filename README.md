# RR Enterprises — Bespoke Luxury Sofa Studio & Manufacturing Platform

A modern luxury web application for **RR Enterprises**, Ongole's premier bespoke sofa designer, custom furniture manufacturer, and furniture-care atelier.

Designed with an editorial architectural aesthetic, rich typography (Cinzel & Playfair Display), responsive 12-column grid system, and high-performance interactive features.

---

## 🌟 Key Features

### 1. Bespoke Editorial Aesthetics
- **Color Palette:** Warm Roman gold (`#D4AF37` / `#C99A32`), rich wine burgundy (`#651F2A`), architectural smoked charcoal (`#171515`), and soft ivory linen (`#F6F0E7`).
- **Typography:** Cinzel brand serif headers, Playfair Display editorial titles, and Plus Jakarta Sans high-legibility body.
- **Glassmorphism & Micro-Interactions:** Custom frosted glass effects, subtle hover states, smooth transitions, and tactile feedback.

### 2. Multi-Page Architecture
- **Home (`/`):** Full 13-section showcase matching luxury atelier mockups (Hero, Brand Statement, Services Showcase, Color Story, Customization Suite, Workshop Story, Works Gallery, Video Showcase, Why Choose Us, Brand Materials, Customer Reviews, Social Reels Showcase, and Final CTA).
- **About (`/about`):** 10-section narrative covering heritage, artisan craftsmanship, bespoke tailoring, workshop tour, why choose us, and brand materials.
- **Services (`/services`):** Complete service portfolio with 2-3-2 hierarchical grid, detailed cards, step-by-step workflow, and custom enquiry pathways.
- **Works & Catalog (`/works`):** Interactive furniture gallery with category filters (Sectionals, Recliners, Sofa-cum-Beds, Custom).
- **Contact & Consultation (`/contact`):** Comprehensive contact page with quick direct action cards, interactive booking form, location map & store hours, FAQ accordion, and social handles.

### 3. Navigation & Global CTAs
- **Unique Desktop Navbar:** Floating smoked glass capsule with Roman monogram emblem, active page pill indicators, direct phone hotline badge, and `"Get in Touch ➔"` master button.
- **Mobile Sticky Navigation:** 100% viewport-fit, zero-overflow sticky header with quick WhatsApp action and full-screen staggered mobile directory.
- **Global Vertical Floating Dock:** Vertically aligned action stack in the bottom-right corner across **ALL** pages:
  1. ⬆️ **Scroll to Top:** Instant smooth scroll to top (automatically shows when scrolled down).
  2. 📅 **Book Now:** Direct shortcut to custom sofa booking & consultation.
  3. 💬 **WhatsApp:** One-tap instant WhatsApp chat with pre-filled message generator.
  4. 📞 **Call:** Instant phone dialer for direct customer support (`099857 04432`).

## 🛠️ Technology Stack

- **Framework:** React 19 + Vite
- **Styling:** Vanilla CSS with custom architectural CSS tokens, fluid clamp scales, and Tailwind utility classes
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Deployment:** Vercel (configured with `vercel.json` SPA rewrites)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/lunacoderl/rr-furnitures.git

# Navigate to project directory
cd rr-furnitures

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
# Build for production
npm run build

# Preview production build locally
npm run preview
```

---

## 🌐 Deployment on Vercel

The project includes `vercel.json` configured for single-page application routing.
1. Push to GitHub (`main` branch).
2. Connect repository to [Vercel](https://vercel.com).
3. Framework Preset: **Vite**.
4. Deploy!
